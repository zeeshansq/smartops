Problem & Solution

Architectural Principles

How SmartOps resolves classical SaaS bottlenecks and security vulnerabilities.

warning

The B2B SaaS Problem Statement

  • 01
    Cross-Tenant Data Leaks:

    In single-DB apps, an un-scoped ORM query can accidentally expose Client A's confidential data to Client B.

  • 02
    Synchronous Server Bottlenecks:

    Invoking external AI APIs or complex reports directly on HTTP threads causes worker timeouts and degraded UX.

  • 03
    Sequential ID Enumeration:

    Sequential integer primary keys (e.g. /orgs/5/) allow attackers to easily scrape and count tenant records.

verified

The SmartOps Enterprise Architecture

  • 01
    Request-Isolated TenantMiddleware:

    Interceptors validate X-Workspace-ID and user roles on every request, scoping queries to request.tenant.

  • 02
    Event-Driven Celery Offloading:

    Heavy tasks return instant 202 Accepted with task_id, processed by Celery + Redis workers in milliseconds.

  • 03
    Cryptographic UUIDv4 Primary Keys:

    All models leverage UUIDv4 identifiers, rendering horizontal resource enumeration mathematically impossible.

API Usage Guide

Interactive Workflow Verification

Obtain stateless access and refresh JWT tokens using email identifier.

curl -X POST http://127.0.0.1:8000/api/v1/auth/token/ \
  -H "Content-Type: application/json" \
  -d '{
    "email": "admin@smartops.com",
    "password": "AdminPass123!"
  }'

Create a new isolated Workspace (tenant). Initiator is automatically set as 'Owner'.

curl -X POST http://127.0.0.1:8000/api/v1/workspaces/ \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Acme Global Enterprise"
  }'

Generate cryptographically hashed API keys scoped to the target workspace header.

curl -X POST http://127.0.0.1:8000/api/v1/billing/api-keys/ \
  -H "Authorization: Bearer <access_token>" \
  -H "X-Workspace-ID: <workspace_id>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Production AI Pipeline Key"
  }'

Trigger asynchronous LLM task generation. Returns instant 202 Accepted with Celery task ID.

curl -X POST http://127.0.0.1:8000/api/v1/ai/generate/ \
  -H "Authorization: Bearer <access_token>" \
  -H "X-Workspace-ID: <workspace_id>" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Summarize Q3 telemetry reports and risk metrics.",
    "model": "gpt-4o"
  }'
OWASP Compliance

Security Controls

PBKDF2 Key Hashing

API keys are hashed using PBKDF2-SHA256. Raw secrets are never stored in plaintext.

DRF Rate Throttling

Anon (20/min) and User (200/min) rate limits prevent brute-force attacks.

Strict HTTP Headers

Enforces X-Frame-Options DENY, X-Content-Type-Options nosniff, and Referrer-Policy.

UUID Obfuscation

All primary keys leverage UUIDv4, eliminating horizontal enumeration risks.
